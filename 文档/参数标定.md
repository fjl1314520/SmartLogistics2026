# 参数标定指南

> 竞赛代码 = 离线标定 + 查表执行。所有"调车"就是改下面这几张表。

## 1. 编译期总开关：`User/zpc_zxc_Parameter.h`

| 宏 | 作用 |
|---|---|
| `WuLiao0` / `WuLiao1` | 初赛 / 决赛物料（升降高度、延时余量） |
| `GivenTestNum` | 给定任务码，跳过扫码（联调用） |
| `Gimbal_MoveRemain` | 抓放动作全局延时余量，越大越慢越稳 |
| `PlateHigh` | 转盘高度 mm，联动升降台脉冲数 |
| `PathDebug` | 只定位不抓放，现场调路径专用 |
| `Fast` | 快速模式（激进速度，路径会漂） |
| `CarSexENABLE` | 决赛物料"车震"抖料使能 |

## 2. 路径点表：`CarBody/Chassis_Path.c`

- 每个路径点 `{vx, vy, ΔYaw, t, K}`：速度、角度变化、匀速拍数、加减速时间（2ms × K）。
- 一维数组 = 固定路线（发车 → 二维码 → 转盘 → 粗加工）。
- 二维数组按**起止颜色**索引：粗加工→精加工、精加工→转盘、回家各有红/绿/蓝三套。
- 标定方法：`PathDebug=1` 只跑不抓，逐段改 `t` 直到停点准确。

## 3. PID 参数：`CarBody/Chassis_PID.c`

- 1 组 Yaw 角环 + 7 组视觉对位环（转盘 / 色环×3 / 色环上物料 / 码垛×3）。
- 内核在 `Control/PID.c`（位置式，带死区 / 积分分离 / 双限幅）。

## 4. 舵机角度：`CarBody/Arm.h`

- Yaw 臂、物料盘三色料仓角、夹爪三态的占空比，机械装配变了才需要动。

## 5. 视觉阈值：`视觉代码/main.py`

- HSV 三色阈值数组、面积过滤范围（物料 1500~30000，色环 5000~100000）。
- 换场地灯光后必须重标，现场保存截图 + 阈值一起记到调车记录。
