# 智能物流搬运 2026 工程

2026 年大学生工程实践与创新能力大赛（广东省工创大赛）**智能物流搬运**赛项的备赛工程。

代码基线来自 2025 赛季省赛冠军开源方案（`../GongXun2025-main/`，STM32F407 + 麦克纳姆轮底盘 + 三轴抓取 + K210 视觉），在其基础上做 2026 赛季适配与调车。

## 快速开始

1. **控制端**：Keil MDK5（需安装 STM32F4xx_DFP **2.17.1** 及以上）→ 打开 `控制代码/Project.uvprojx` → 编译 → ST-Link / JLink 烧录。
2. **视觉端**：MaixPy IDE 打开 `视觉代码/main.py`，串口波特率 115200，烧录到 K210。
3. **上电流程**：按键启动 → 陀螺仪零点校准 → 自动执行赛题流程（`main.c` 为顺序脚本）。

## 与参考代码（2025 冠军方案）的差异与待办

- [ ] **陀螺仪适配（必做）**：参考代码用 HWT101，我方为 JY61P。两者都是维特系串口 IMU，协议相近（JY61P 默认 0x55 帧头、115200），需按《JY61P 产品资料》（见 `../开发资料/`）修改 `HWT101.c` 的帧解析，并核对 UART2 接线。
- [ ] **修已知 bug**：`Chassis_Reset()` 陀螺仪校准为累加式且被调用两次，零点会被挪走——建议改为赋值 `HWT101_CheckYaw = HWT101_Yaw;`。
- [ ] **加超时保护**：`Camera_GotoMode()` / `QR_Scan()` 是无超时死等，视觉或二维码失联会全场卡死——建议加超时计数 + 降级策略。
- [ ] **清理死代码**：`Mecanum.c` / `XiaoHao.c` 不在编译列表（旧车残留，引用了不存在的头文件），确认无用后删除。
- [ ] 按新赛场尺寸重新标定 `Chassis_Path.c` 路径点表。

## 赛题流程（main.c 顺序脚本）

发车 → 扫二维码取任务码 → 转盘取料（视觉对位抓 3 个）→ 粗加工区放料/取料 → 精加工/码垛 → **第二圈重复** → 回发车区。

详细代码分析见工作区《2026仓库控制代码分析报告.md》。
